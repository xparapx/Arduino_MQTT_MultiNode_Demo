## 8. 발표 때 심사위원이 물을 법한 질문 (대비용)

1. "1,000 ppm 기준의 출처는?" → 학교보건법 시행규칙 교실 유지기준(확인) + 센서 데이터시트 정확도(SCD30 ±30 ppm ±3%).
2. "방학이 73일 안에 있는데 39%는 학기 중 값인가?" → §1 #5. 학기 중만 56%라고 답할 수 있으면 오히려 강점.
3. "레짐 비율은 GMM 결과인가?" → 4분면 규칙(표준화 z>0.5). GMM은 허브의 실시간 판정용. 둘의 관계를 한 문장으로.
4. "r²가 0.1인데 재실이 원인이라 할 수 있나?" → 유의하지만 설명력 작음, 창문 개폐 미기록, 탐지 과소 — 한계로 답하면 됨.
5. "비전 노드가 좌표도 보내면 프라이버시는?" → 얼굴·영상 없음, 5분 중앙값 인원과 대략 위치뿐.
6. "제어가 실제로 공기를 바꿨나?" → 아직 평가 전(가동 5일) — 다음 사이클. 솔직하게.
7. "그림 10의 사례는 왜 420 ppm까지 안 내려가나?" → 사람이 남아 있어 새 평형; 감쇠 구간만 적합. 사례 교체 권장.

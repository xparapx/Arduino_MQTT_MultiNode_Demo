## 3. 디자인 체계 (모든 차트·도식 공통)

1. **글자는 두 단계뿐** — 제목(굵게)과 그 밖의 모든 글자. 그림을 실제 인쇄 크기(mm)로 만들고 그 크기 그대로 넣어 글자 크기를 보존한다: 보고서 10/9pt(폭 159mm), 포스터 20/16pt(칸 143×85mm).
2. **색은 의미에만** — CO₂ 파랑 `#2f6fb5`, VOC 주황 `#d9772b`, 청정·강조 민트 `#1fa97f`, 복합 보라 `#7a5bb5`, 기준선 빨강 `#d64545`, 잉크 남색 `#14283c`. 나머지는 무채색.
3. **한 그림 한 메시지** — 그림 제목이 곧 결론.
4. **잉크 최소화** — 위·오른쪽 축선 제거, 옅은 가로 격자만.

## 4. 보고서 구성의 뼈대

- 관점: **데이터 기반 소셜 임팩트** + 공동체 데이터 탐구 사이클 7단계(공동체 문제 발견 → 측정 설계 → 데이터 수집 → 분석·모델링 → 인사이트 → 확장(제어) → 제안·공유).
- 강조점: 계획(설계안 도출) 대비 초과 달성(플러그 16대 실제 가동), 독창성 5가지(원인 분류 / 사람을 찍지 않는 AI / 나쁜 데이터로는 스위치를 만지지 않는다 / 스스로 점검하는 모델 / 개선의 비용까지 측정).
- 사실 관계: 센서 노드는 **납땜 없음**(Grove Base Shield + I2C 케이블). 모델 후보 비교·교체는 "정기적으로"(매시간 아님).

## 5. 아직 안 된 것 — 다음 세션에서 할 일

1. **한/글에서 열어 확인(가장 중요)**: 자동 검증(COM)이 화면 잠금 때문에 보안 대화상자를 누르지 못해 실패했다. 구조 검사(zip·XML·그림/서식 참조)는 통과. 특히 **포스터가 1쪽에 들어가는지** 확인할 것 — 칸 높이를 양식 그대로 두고 줄 수를 보수적으로 추정해 넣었지만(`poster_fill.py`가 칸별 추정 높이를 출력) 실제 조판은 미확인. 넘치면 해당 칸의 글을 줄이거나 본문을 20pt → 19pt로.
   - 검증 스크립트: `poster3/hwp_check4.py`(환경변수 `HWP_SRC`, `HWP_PDF`). 화면이 잠겨 있지 않아야 한다(실제 마우스 클릭 필요).
2. **사진**: 보고서 2장의 "[사진 넣는 자리]" 상자와 포스터 성찰 칸 마지막 줄(파란 글씨)은 사진을 넣고 지워야 한다.
3. **역할 분담·소감 문구**는 계획서 기반 초안 — 지도교사 확인 후 학생 말로 다듬기.
4. 대시보드 화면을 보드 실화면으로 바꾸려면: 보드 접속이 되는 자리에서 `capture_cdp.mjs`의 포트를 8501로 바꿔 캡처 → `figs_html.py` 재실행 → `build_report.py`.
5. 분석 창을 10월까지 늘리려면 `prep.py`의 `N_RAW_SEP` 절단을 풀고 본문 수치를 함께 고칠 것(재실 감지는 9-18 이후 데이터 없음).

## 6. 이 PC 환경에서 알아둘 것

- 학교 유선망에서는 Tailscale이 막혀 보드 접속이 안 될 때가 있다(먼저 `tailscale status`로 자기 노드가 online인지 확인).
- Edge 헤드리스 캡처는 Git Bash에서 파일이 안 생길 수 있어 node(CDP) 또는 PowerShell `Start-Process`로 실행한다.
- 한/글 COM의 파일 접근 보안 대화상자는 UIA invoke로 닫히지 않고 실제 마우스 클릭만 통한다.

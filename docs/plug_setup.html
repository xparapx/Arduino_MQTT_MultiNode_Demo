Shelly Plug S Gen3 설정 매뉴얼multinode_aq 액추에이터 · 공기청정기/환풍기용 스마트플러그 프로비저닝 — 플러그 1대당 약 10분, 8대 일괄 작업 가능

✅ 미리 알아둘 것 설정은 플러그별로 완전히 독립입니다. 교무실에서 8대를 전부 설정한 뒤 나중에 교실로 옮겨도 재설정이 필요 없습니다 (학교 전체가 같은 SSID이고, 제어는 클라우드 브로커 경유라 플러그의 IP가 바뀌어도 무관). 유일하게 망가지기 쉬운 것은 "어느 플러그가 어느 교실용인지"이므로 7단계(스티커 + 매핑표)를 절대 건너뛰지 마세요.

기타폰 또는 노트북(WiFi 전환용) · 유성펜/라벨 스티커 8장
⚠️ 비밀번호 입력 시복사–붙여넣기를 권장합니다. 직접 타이핑할 경우 대소문자·숫자를 두 번 확인하세요. WiFi 비밀번호가 틀리면 플러그가 AP 모드로 되돌아오고, MQTT 비밀번호가 틀리면 connected:false에서 멈춥니다.

1. 전원 연결 → 임시 AP 확인

  1. 플러그를 콘센트에 꽂습니다. LED가 파란색으로 켜지면 미설정(AP 모드) 상태입니다.
  2. 폰/PC의 WiFi 목록에 ShellyPlugSG3-XXXXXXXXXXXX가 나타나는지 확인합니다. 뒤 12자리는 플러그 고유 MAC — 이 값이 곧 MQTT prefix가 되므로 지금 메모해 두면 7단계가 편합니다.

2. 임시 AP 접속 → 설정 화면

  1. 폰/PC WiFi에서 ShellyPlugSG3-…에 연결합니다 (비밀번호 없음).
  2. "인터넷 연결 없음" 경고는 무시하고 연결 유지를 선택합니다 (폰이 데이터로 자동 전환하려 하면 거부).
  3. 브라우저 주소창에 직접 입력: http://192.168.33.1 (반드시 http — https 아님)
⚠️ PC로 할 경우PC WiFi를 Shelly AP로 바꾸는 동안 학교망·인터넷이 끊깁니다. 작업 중인 것을 마친 뒤 진행하고, 4단계 후 PC WiFi를 학교망으로 되돌리는 것을 잊지 마세요.

3. 학교 WiFi 등록

  1. 메뉴 Settings → Wi-Fi → Wi-Fi 1 settings
  2. Network: wi_cne_class_S_2.4G (드롭다운에서 선택 또는 직접 입력) · Password 입력
  3. Enable Wi-Fi 토글 ON → Save settings
🔧 토글이 회색으로 잠겨 안 켜질 때 (흔한 UI 버그) ① Network 칸을 클릭해 값을 다시 타이핑하고 칸 바깥을 한 번 클릭해 입력을 확정한 뒤 토글 — ② 그래도 안 되면 토글 꺼진 채로 Save settings 먼저 누르고 F5 새로고침 → 토글이 풀려 있음 → 켜고 다시 Save. (실측: Save 먼저 방식으로 해결됨)
  • Wi-Fi 2, Roaming(−80 / 60 s), Static IP는 기본값 그대로 둔다 (IP 고정은 나중에 라우터 DHCP 예약으로)

4. 학교망 복귀 → 접속 확인

  1. 저장하면 플러그가 재부팅하며 학교망에 붙고, 폰/PC는 Shelly AP에서 자동으로 끊깁니다.
  2. 폰/PC WiFi를 wi_cne_class_S_2.4G로 되돌립니다.
  3. 브라우저에서 http://shellyplugsg3-xxxxxxxxxxxx.local (소문자, 1단계에서 메모한 MAC) 또는 설정 화면에서 확인한 IP(예: http://192.168.1.224)로 접속되면 성공.

확인용 RPC (선택): http://<플러그IP>/rpc/WiFi.GetStatus → "status":"got ip", rssi가 −70보다 크면(예: −47) 신호 양호.

6. 재부팅 → MQTT 접속 확인

⚠️ MQTT 설정은 저장만으로 적용되지 않습니다 — 재부팅 필수 Save 후에도 connected:false인 것이 정상입니다. 재부팅해야 새 설정으로 접속합니다.
  1. 웹 UI에서 재부팅 (Settings 하단 Reboot) 하거나, 콘센트에서 뽑았다 다시 꽂습니다.
  2. 약 30초 후 브라우저에서 http://<플러그IP>/rpc/MQTT.GetStatus 접속 → {"connected":true}가 나오면 성공.
🔧 connected:false가 계속될 때 ① 비밀번호 대소문자 재확인 (첫 글자 K) ② Server 주소 끝 :8883 포함 여부 ③ Connection type이 Default TLS인지 ④ 다시 저장 → 재부팅. 그래도 안 되면 관리자(Claude 세션)에게 — 허브에서 브로커 접속 로그로 원인을 좁힐 수 있음.

8. 최종 동작 테스트 (플러그당 30초)

  1. 같은 망의 브라우저에서: http://<플러그IP>/rpc/Switch.Toggle?id=0 → 릴레이 딸깍 소리 확인, 한 번 더 눌러 원복.
  2. 원격(MQTT) 경로는 8대 설정 완료 후 관리자(Claude 세션)가 허브에서 일괄 검증: <prefix>/command/switch:0에 on/off 발행 → status/switch:0 피드백 확인.

9. 운용 투입 전 마무리 (교실 배치 시)

  • AP 모드 끄기 — Settings → Wi-Fi → Access Point 비활성. 켜둔 상태면 누구나 비밀번호 없이 설정 화면에 들어올 수 있음 (8대 설정이 전부 끝난 뒤에 끌 것 — 끄면 재설정 시 리셋 버튼 5초 필요)
  • 라우터에서 플러그 IP DHCP 예약 (관리 편의용 — MQTT 제어에는 필수 아님)
  • 공기청정기 뒷면 전원을 ON에 고정하고 플러그에 연결 — SS-3631PW는 통전 복구형이라 플러그 ON=가동 (실측 확인 2026-09-01)
  • 환경 노드·비전 노드의 USB 전원은 이 플러그에 절대 같이 꽂지 않기 — OFF 판정 때 센서까지 꺼짐 (비전 노드용 재시작 플러그는 별도)
  • 펌웨어 자동 업데이트는 기본 꺼짐 — 수동 업데이트만 사용

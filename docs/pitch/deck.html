05 · DATA ENGINEERING

데이터 엔지니어링 — 믿을 수 있는 데이터 만들기

모델보다 먼저, "이 데이터를 믿어도 되는가"에 답하는 4단계 관문.

왜 보간하지 않는가

결측을 그럴듯한 값으로 메우면 "판단 보류"가 "잘못된 확신"이 된다. 이 시스템의 모든 화면은 모르는 것을 모른다고 표시한다 — 회색 결측 칸, 제외 칩, ≥ 기호(관측 하한).

비전 데이터의 원칙

카메라 노드는 5분 버킷의 평균·중앙값·최대 인원과 좌표만 남긴다. 영상 프레임은 저장도 전송도 하지 않는다 — 교실에 놓아도 되는 AI의 조건.

06 · INFERENCE MODEL

추론 모델 — 왜 GMM인가, 왜 하이브리드인가

발생원이 다른 두 축(CO₂=사람, VOC=물질)을 4개의 "레짐"으로 읽고, 규칙이 최종 행동을 결정한다.

고정 스케일 CO₂×VOC 평면 · GMM 4성분

축이 물리 상수로 고정 — 재학습해도 4분면 의미가 안 변해 "지난주와 비교"가 성립.

모델 선택 근거 3가지

  • 비지도 — "나쁨"의 정답 라벨이 없는 문제. 상태(레짐)를 스스로 발견해야 함
  • 확률 소속 — 경계값을 단칼에 자르지 않고 부드럽게 (K-means 대비 장점)
  • 해석 가능 — 4개 성분 = 발생원 조합(사람×물질)과 1:1 대응, 심사·검증 가능

ML을 그대로 믿지 않는다 — 3층 하이브리드

  • 층1 탐색 RobustScaling 상대 레짐 — 보는 도구, 판정 금지
  • 층2 진단 고정 스케일 GMM + 45분 평활 — "지금 어떤 상태인가"
  • 층3 행동 임계 규칙 + 히스테리시스(ON 1000/OFF 700) + 최소 가동 10분 — 떨림 방지, 검증 가능한 최종 결정

모델도 심사를 받는다 (거버넌스)

격주(2주)마다 재학습 후보를 만들고 4분면 구분 유지 ∧ (로그우도 +2% ∨ 중심 이동 ≥0.25)를 통과해야 승격. 모든 결정은 모델 이력으로 기록 — gmm_v1 → …

07 · OPERATION & INSIGHT

모델 운용 — 숫자가 행동이 되기까지

추론 결과는 매시간 대시보드로 흘러, 네 가지 질문에 답한다.

① 지금 무슨 상황인가 — 레짐 스위칭 밴드

"몇 교시에, 어느 교실이, 왜 나빠지는가"가 한눈에 — 시간표와 겹쳐 읽는 순간 심사위원의 "아하".

② 무엇을 해야 하는가 — 행동지침 + 히스테리시스
인체 → 환기 필요 · CO₂ 1,129 ppm

레짐(ML)이 게이트를 열고, 임계(규칙)가 방아쇠 — 껐다켰다 떨림은 밴드가 막는다.

③ 앞으로 어떻게 되는가 — 30분 예측 경보
748 ppm 지금
→
1,040 ppm +30분

Ridge 회귀가 "나빠지기 전"에 알려준다 — ⚠ 임계 초과 예상 → 쉬는 시간에 미리 환기.

④ 이 판단을 믿어도 되는가 — 검증 루프
  • 재실 인원 × CO₂ Spearman ρ ≈ 0.5+ — 비전·환경 두 센서가 서로를 교차 검증
  • 유효 범위 화면 — 오늘 판정이 성립하는 조건을 항상 공개
  • QC 탈락 교실은 "판정 보류" — 모르면 모른다고 말하는 시스템
